# Screen recording checklist

1. Start the app with `npm run dev` and show the CraveCorner hero.
2. Search for “chicken” and demonstrate that results update.
3. Select Pakistani Food, then clear the search while keeping the category selected.
4. Open a food detail page, change quantity, add it to the cart, and show the live badge.
5. Favourite an item and open the Favourites page.
6. Increase/decrease quantity, remove an item, and show the total in Cart.
7. Open checkout, submit once with missing fields to show validation, then complete the simulated order.
8. Show the generated confirmation number and return to the menu.

On Windows, use Snipping Tool’s screen recorder (`Win + Shift + R`) or OBS Studio. Do not record payment details; this project intentionally has no payment flow.
